# Loanzyra starter (mobile-friendly PWA)

This is a free starter website/PWA for a loan-provider information directory.

## Publish free using a phone
1. Open github.com in Chrome and sign in / create a GitHub account.
2. Create a **public** repository named `loanzyra`.
3. Choose **Add file → Upload files** and upload `index.html`, `manifest.json`, and `sw.js` from this ZIP.
4. Open repository **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Open the published URL on your phone.
7. In Chrome, use menu ⋮ → **Add to Home screen** (or Install app if shown).

## Important
- The starter intentionally contains no lender listings. Add providers only after checking the current official lender website and relevant RBI records.
- RBI's DLA directory is based on information submitted by regulated entities; inclusion is not RBI approval or endorsement.
- Do not publish unverified interest rates, fees, loan limits, ratings or approval claims.
- This is an information directory, not a lender, loan facilitator, or financial advice service.
- Do not collect Aadhaar, PAN, OTP, PIN, bank passwords or sensitive financial documents in this starter.
- GitHub Pages hosting is free for public repositories, but availability/terms can change. A custom domain is not included.
